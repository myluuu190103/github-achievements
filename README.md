# GitHub Achievements

Repo thử nghiệm để tìm hiểu cách GitHub Achievements được trao.

Không có mã nguồn thật ở đây — chỉ là nơi thực hành các thao tác trên GitHub
(issue, pull request, commit đồng tác giả) và quan sát huy hiệu xuất hiện trên
trang hồ sơ.

## Các huy hiệu và điều kiện

| Huy hiệu | Điều kiện | Bậc |
|---|---|---|
| Quickdraw | Đóng một issue hoặc PR trong vòng 5 phút kể từ khi mở | — |
| YOLO | Merge một pull request mà không qua review | — |
| Pull Shark | Số pull request được merge | 2 / 16 / 128 / 1024 |
| Pair Extraordinaire | Commit có `Co-authored-by:` nằm trong PR đã merge | 1 / 10 / 24 / 48 |
| Starstruck | Số sao của một repo do mình tạo | 16 / 128 / 512 / 4096 |
| Galaxy Brain | Câu trả lời được chấp nhận trong Discussions | 2 / 8 / 16 / 32 |
| Heart On Your Sleeve | Thả cảm xúc ❤️ vào một issue, PR hoặc bình luận | — |
| Public Sponsor | Tài trợ một dự án hoặc cá nhân qua GitHub Sponsors | — |

## Lưu ý

- Chỉ hoạt động trong **repo public** mới được tính.
- Cần bật *Settings → Public profile → Show Achievements on my profile*.
- Huy hiệu cập nhật trễ, thường vài phút đến vài giờ.
- `Arctic Code Vault`, `Mars 2020`, `Open Sauced` đã ngừng trao.
